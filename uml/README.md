# UML-модель динамического поведения SubScope

Лабораторная работа №5. Модель построена на основе [SRS v0.4](../srs/srs.md), [SDD](../sdd/sdd.md) и плана v3 и описывает, **как система ведёт себя во времени**: кто и какие функции запускает, в каком порядке выполняются действия, как меняются состояния объектов и какими сообщениями обмениваются части системы.

## Связи между диаграммами

Диаграммы образуют цепочку уточнений: прецедент (что делает система для актёра) → диаграмма активности (в каком порядке и кем выполняются действия) → диаграмма последовательности (какие объекты обмениваются какими сообщениями) → диаграмма состояний (как эти сообщения меняют объект). Одни и те же условия встречаются на всех уровнях: например, «5 неудачных попыток» — это альтернативный поток А1 UC-02, ветвь на рисунке ad-1, фрагмент `opt` на sq-1 и переход «Вход доступен → Временно заблокирована» на sm-2.

| Прецедент | Активность | Последовательность | Состояния |
|-----------|------------|--------------------|-----------|
| UC-02 Войти в систему | ad-1 | sq-1 | sm-2 (регион «Вход») |
| UC-04 Добавить подписку (+UC-26, UC-27) | ad-2 | sq-2 | sm-1 (переход в «Активна») |
| UC-07 Изменить статус подписки | ad-4 (действие с кандидатом) | — | sm-1 |
| UC-11 Просмотреть кандидатов на отмену | ad-4 | — | sm-1 («Отменена») |
| UC-14 Привязать Telegram | — | sq-5 | sm-2 (регион «Канал») |
| UC-19 Заблокировать пользователя | — | — | sm-2 («Заблокирована администратором») |
| UC-20 Загрузить курсы валют | — | sq-4 | — |
| UC-21 Отправить напоминания (+UC-25) | ad-3 | sq-3 | sm-3 |
| UC-22 Перенести даты списания | — | — | sm-1 (внутренний переход «Платная») |

## Построение изображений

```
python uml/tools/uml.py              # все модели
python uml/tools/uml.py sm-1-subscription
```

Нужны Graphviz и Node.js 18+; mermaid-cli загружается командой `npx` автоматически. Изображения в `images/` в репозитории всегда соответствуют моделям: модель и её изображение меняются в одном коммите.
