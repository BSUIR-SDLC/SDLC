# Глоссарий проекта

Проект: 3D Security Monitoring Center. Версия глоссария: 1.0.

Глоссарий собирает термины предметной области и модели поведения системы. Термины используются в спецификации требований [srs/srs.md](../srs/srs.md), описании дизайна [sdd/sdd.md](../sdd/sdd.md), описании прецедентов [use-cases.md](use-cases.md) и на диаграммах UML каталога [uml](.). Если термин в разных документах понимается по-разному, верным считается определение из этого глоссария.

## Термины предметной области

| Термин | English | Определение | Где используется |
|---|---|---|---|
| Агент | Agent | Служба Windows на контролируемом компьютере, которая собирает события безопасности и отправляет их серверу | UC-09, AD-01, SD-02 |
| Аудитор | Auditor | Роль пользователя, которая только читает журнал аудита и проверяет его целостность | UC-07 |
| Администратор | Administrator | Роль пользователя, которая управляет системой и проводит учебные тревоги | UC-02 – UC-08 |
| Важность | Severity | Уровень опасности инцидента: низкая, средняя, высокая, критическая | UC-09, AD-01 |
| Время реакции | Reaction time | Время от создания инцидента до взятия его в работу оператором | UC-08 |
| Журнал аудита | Audit log | Таблица действий пользователей, в которой каждая запись содержит хеш предыдущей записи | UC-07, UC-10 |
| Зона | Zone | Категория помещения: обычная, служебная или режимная. Влияет на важность инцидента | AD-01 |
| Инцидент | Incident | Запись о нарушении, созданная сервером при срабатывании правила обнаружения | UC-04 – UC-06, ST-01 |
| Карточка хоста | Host card | Панель консоли с именем, адресом, пользователем, событиями и инцидентами хоста | UC-03 |
| Консоль | Console | Приложение на Unreal Engine 5 с 3D-сценой объекта, через которое работают пользователи | все прецеденты пользователей |
| Наблюдатель | Observer | Роль пользователя, которая только смотрит 3D-карту и список инцидентов | UC-02, UC-03 |
| Оператор безопасности | Security operator | Роль пользователя, которая разбирает инциденты: меняет статус и пишет комментарии | UC-04 – UC-06 |
| Правило обнаружения | Detection rule | Условие над потоком событий: тип события, окно времени, порог и важность | UC-09, AD-01 |
| Пульсация | Pulse | Мигание хоста на сцене, показывающее открытый инцидент | ST-02 |
| Сервер | Server | Программа на C++, которая принимает события, применяет правила и обслуживает консоли | AD-01, SD-01, SD-02 |
| Сеанс учений | Drill session | Время между запуском и завершением учебной тревоги, в течение которого инциденты получают признак drill | UC-08 |
| Скользящее окно | Sliding window | Интервал времени перед текущим событием, в котором подсчитываются похожие события | AD-01 |
| Событие | Event | Запись о действии на хосте, например неудачный вход или подключение USB-накопителя | UC-09, AD-01 |
| Состояние хоста | Host state | Цвет хоста на сцене: норма, предупреждение, инцидент, агент молчит | ST-02 |
| Статус инцидента | Incident status | Этап разбора инцидента: новый, в работе, решён, ложное срабатывание | ST-01, UC-05 |
| Учебная тревога | Training drill | Проверка операторов: генератор воспроизводит атаку на стендовых хостах, а сервер замеряет время реакции | UC-08 |
| Хост | Host | Контролируемый компьютер с установленным агентом | UC-03, ST-02 |
| Heartbeat | Heartbeat | Сигнал работы, который агент отправляет серверу каждые 30 секунд | UC-11, ST-02 |

## Термины модели поведения

| Термин | English | Определение |
|---|---|---|
| Актёр | Actor | Роль, которую человек, внешняя система или время играет по отношению к системе |
| Прецедент | Use case | Последовательность действий системы в ответ на событие, которое инициирует актёр |
| Поток событий | Flow of events | Пошаговое описание прецедента: основной поток, альтернативные потоки и потоки ошибок |
| Предусловие | Precondition | Условие, которое должно выполняться до начала прецедента |
| Постусловие | Postcondition | Условие, которое выполняется после завершения прецедента |
| Включение | Include | Связь, при которой прецедент всегда выполняет поведение другого прецедента |
| Расширение | Extend | Связь, при которой прецедент дополняется поведением другого прецедента только при условии |
| Обобщение | Generalization | Связь, при которой актёр-потомок наследует все прецеденты актёра-родителя |
| Дорожка | Swimlane | Область диаграммы активности, показывающая, кто выполняет действие |
| Линия жизни | Lifeline | Участник диаграммы последовательности и время его существования |
| Фокус управления | Execution specification | Прямоугольник на линии жизни, показывающий время выполнения операции |
| Сторожевое условие | Guard | Условие в квадратных скобках, при котором выполняется переход или ветвь |
