# Образцы ответов API НБ РБ

Получены 19.11.2026 при проверке интеграции (POC, задача T-03.1, REQ-POC-001):

- `rates-2026-11-19.json` — `GET https://api.nbrb.by/exrates/rates?periodicity=0` (в ответе 30 валют; оставлены USD, EUR, PLN, JPY, RUB — валюты с масштабом 1, 10 и 100);
- `rates-2026-10-01.json` — то же с параметром `ondate=2026-10-01` (курс на прошедшую дату; оставлены USD, EUR, RUB).

Вывод POC: API доступно без ключа, возвращает курсы на текущую и прошедшую дату в одном формате; масштаб `Cur_Scale` бывает больше 1, поэтому стоимость единицы валюты считается как `Cur_OfficialRate / Cur_Scale` (ADR-0004, алгоритм А1 SDD).
