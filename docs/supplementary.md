# Дополнительные спецификации «Полки»

| Свойство | Правило | Способ проверки |
|---|---|---|
| Автономность | Одна страница с локальными скриптами, русский интерфейс, без сервера и сети | Открыть app/index.html с диска и добавить книгу |
| Сохранность | Снимок записывается одним setItem до обновления экрана | При повторном открытии совпадают карточки и цель |
| Целостность | Идентификаторы непусты и уникальны, позиция целая и принадлежит [0, N], статус соответствует позиции | Загрузить файл с повторным id либо страницей N+1. Проверить сохранность прежней полки |
| Завершение | Повтор страницы N сохраняет дату. Возврат ниже N очищает её | Завершить, повторить отметку и вернуться на предыдущую страницу |
| Календарь | Месяц и дата определяются местным временем. Суммируются только положительные изменения позиции в выбранном месяце | События за соседние месяцы должны давать разные итоги |
| Исправление | При уменьшении позиции история сохраняется. Новое продвижение от исправленной позиции учитывается снова | При отметках 10 → 7 → 9 итог положительных продвижений равен 12 |
| Переносимость | Формат совпадает с представлением 004-information SDD; корректный импорт заменяет снимок целиком | Экспортировать, изменить полку, импортировать и перезагрузить |
| Граница MVP | Отбор карточек по статусу отложен по плану 1.1 | На полке отображаются все карточки |
