### 1. Требования к производительности и надёжности
* **Время отклика API (`NFR-1`):** Обработка входящего запроса `POST /command` (включая валидацию токена и мутацию состояния) не должна превышать 100 мс.
* **Непрерывность работы (`NFR-2`):** Модуль должен стабильно функционировать не менее 24 часов в асинхронном цикле событий без утечек памяти и блокировки таймера.
* **Атомарность обновления (`REQ-BR-003`):** Изменение интервала $N$ или температурного смещения должно применяться со следующего цикла генерации без потери текущего состояния и состояния гонки (*race condition*).

### 2. Требования к безопасности
* **Авторизация (`FR-7`):** Все запросы к эндпоинту `/command` обязаны содержать валидный заголовок `Authorization: Bearer <TOKEN>`. При отсутствии или несовпадении токена система возвращает статус `401 Unauthorized` без изменения состояния.

### 3. Ограничения среды и совместимости
* **Стек технологий (`ADR-001`):** Python 3.10+, асинхронный веб-фреймворк FastAPI + ASGI-сервер Uvicorn.
* **Кроссплатформенность (`NFR-3`):** Поддержка запуска в ОС Windows и Linux через интерфейс командной строки (CLI).
* **Формат обмена (`BR-2`):** Строгая типизация JSON (`temperature` — float, `motion` — boolean, `timestamp` — Unix epoch int).
