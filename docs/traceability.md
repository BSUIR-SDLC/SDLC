# Матрица трассировки системных требований

Матрица связывает системные требования с архитектурными компонентами и типами проверок. Исходные идентификаторы FR/NFR необходимо сверить с SRS ЛР3 перед сдачей.

| Системное требование | Компонент | Основная проверка |
|---|---|---|
| SYS-FR-001, SYS-FR-002 | Authentication, API | Успешная регистрация/вход и отказ при неверных данных |
| SYS-FR-003 | Authorization, Persistence | Попытка чтения и изменения чужой сущности отклоняется |
| SYS-FR-004, SYS-FR-005 | Goals Service | CRUD и изменение статуса цели |
| SYS-FR-006, SYS-FR-007 | Habits Service | Создание привычки, отметка выполнения, отсутствие дубликатов |
| SYS-FR-008, SYS-FR-009 | Calendar Service | Создание события и отображение на нужной дате |
| SYS-FR-010 | Notes Service | CRUD заметки и проверка владения |
| SYS-FR-011, SYS-FR-012, SYS-FR-013 | Teams Service, Authorization | Приглашение, членство, проверка роли |
| SYS-FR-014 | API и прикладные сервисы | Проверка фильтрации и сортировки |
| SYS-FR-015 | Export Service, Authorization | CSV валиден; чужие данные не экспортируются |
| SYS-NFR-001 | Конфигурация окружения | Проверка HTTPS/TLS |
| SYS-NFR-002 | Authentication | Проверка отсутствия открытых паролей в хранилище |
| SYS-NFR-003, SYS-NFR-007 | API | Негативные тесты валидации и формата ошибок |
| SYS-NFR-004 | Authorization | Проверка прав на каждом защищённом маршруте |
| SYS-NFR-005, SYS-NFR-009 | Persistence Layer | Тест ограничений целостности и отката транзакции |
| SYS-NFR-006 | API и сервисы | Нагрузочный тест с зафиксированными параметрами |
| SYS-NFR-008 | Все серверные модули | Unit-тесты и проверка разделения ответственности |
| SYS-NFR-010 | Документация и процесс PR | Проверка обновления документации вместе с API/архитектурными изменениями |
