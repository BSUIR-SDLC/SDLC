# Итоговый план реализации по итерациям

В ходе двух раундов переговоров с Заказчиком были скорректированы приоритеты и составлен план с учетом жесткого дедлайна (30 дней).

## Изменения по результатам обсуждения:
1. Добавлена функция подачи жалоб (REQ-FUNC-004) и редактирования отзывов.
2. Отложена загрузка фото для мест (в рамках REQ-FUNC-008) для экономии времени.
3. Для соблюдения дедлайна в команду добавлен Junior-разработчик.

## Итерация 1 (Дни 1–10)
* Создание отзыва (текст + оценка + фото).
* Средний рейтинг в карточке места.
* Блокировка пользователей модератором.

## Итерация 2 (Дни 11–20)
* Очередь жалоб и скрытие контента.
* Подача жалоб пользователями.
* Редактирование своего отзыва (Junior под контролем Senior).

## Итерация 3 (Дни 21–30)
* Ответы арендодателя на отзывы.
* Добавление мест арендодателем (без загрузки фото).
* Аудит действий модератора.
