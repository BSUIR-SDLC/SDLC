# Динамическое моделирование Task Manager

Версия 0.3. Подготовила Климова Авелина Алексеевна. Дата: 23.11.2026.

Проектная модель описывает создание и выполнение личных дел, категории, подзадачи, календарное повторение, напоминания и административные действия. Текущий объём 0.3 определён в [SRS](../srs.md#version-03-scope); план P2 версии 0.2 сохранён как историческая база.

Копия Visio сохраняет пользовательскую компоновку; в схеме Г подпись хранилища приведена к SQLite согласно текущему стеку. Оригинал вне репозитория не изменён. Исходники PlantUML описывают семантику; их расположение при генерации может отличаться.

Документация и модели не подтверждают реализацию. Проверки сессий, разграничения доступа, SMTP, повторения и производительности остаются Planned. Папка `lab1/` содержит отдельный «Калькулятор Жизни», а не Task Manager. Новые функции требуют оценки сроков; прежний бюджет и срок P2 не распространяются на расширение автоматически. Изменения подготовлены локально; отправка ветки и внешнее рецензирование не подтверждены.
