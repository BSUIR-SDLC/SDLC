# Дополнительные спецификации проекта «Должок»

Версия 0.1 · 31.10.2026

Дополнительные спецификации содержат требования, которые не относятся к конкретному варианту использования: качество, ограничения, интерфейсы, правила данных. Все требования имеют идентификаторы из SRS (`srs/srs.md`).

## 1. Функциональные правила

- Сумма долга - положительное число с двумя знаками после запятой (REQ-DEBT-002).
- Срок возврата, если указан, не раньше даты долга (REQ-DEBT-004).
- Сумма погашения больше нуля и не больше остатка (REQ-PAY-002).
- Групповой долг: от трёх до пяти участников, сумма делится поровну, сумма долей совпадает с исходной до копейки (REQ-DEBT-008).

## 2. Производительность

- Главная страница загружается не более чем за 2 с при 100 активных долгах (REQ-PERF-001).
- Система обслуживает не менее 500 одновременных пользователей (REQ-PERF-002).

## 3. Безопасность

- Пароли хранятся только в виде хэша с солью (REQ-SEC-001).
- Передача данных только по HTTPS (REQ-SEC-002).
- Пользователь видит только свои долги (REQ-SEC-003).
- Защита от SQL-инъекций и XSS (REQ-SEC-004).
- Блокировка входа на 15 минут после пяти неудачных попыток (REQ-SEC-005).

## 4. Надёжность и целостность

- Создание долга и письма в outbox выполняются в одной транзакции (ADR-0005).
- Остаток долга согласован с суммой погашений при любом сбое (REQ-QUAL-007).
- Ежедневное резервное копирование БД (REQ-QUAL-002).

## 5. Удобство использования

- Интерфейс корректно отображается на экранах от 360 px (REQ-UI-004).
- Просроченные долги выделяются визуально (REQ-UI-003).
- Ошибки ввода показываются у соответствующего поля (REQ-UI-005).

## 6. Сопровождаемость и развёртывание

- Система разворачивается в Docker одной командой (REQ-QUAL-006).
- Журналируются ошибки сервера, неудачные попытки входа и отправка уведомлений без паролей и текстов комментариев (REQ-QUAL-005).

## 7. Интерфейсы

- Клиент (React) обращается к серверу (Spring Boot) по REST API в формате JSON через HTTPS (ADR-0001, ADR-0002).
- Почтовый сервис: внешний SMTP (REQ-NOT-001).
- База данных: PostgreSQL 16 (ADR-0003).

## 8. Ограничения

- Язык интерфейса - русский.
- Серверная часть - Java, Spring Boot 3.
- Реальные денежные переводы и онлайн-оплата не выполняются.
- Пересчёт валют по курсу не выполняется.
