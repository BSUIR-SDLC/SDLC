# Глоссарий проекта «Должок»

Версия 0.1 · 31.10.2026

| Термин | Определение | Связь с SRS |
|--------|-------------|-------------|
| Долг | Запись о денежной сумме, которую должник обязан вернуть кредитору | REQ-DEBT-001 |
| Кредитор | Пользователь, который одолжил деньги | REQ-DEBT-001 |
| Должник | Пользователь, который занял деньги | REQ-DEBT-001 |
| Направление долга | Признак «Я одолжил(а)» или «Я занял(а)», определяющий роль автора записи | REQ-DEBT-001 |
| Друг | Пользователь, с которым связь подтверждена обеими сторонами | REQ-FR-002 |
| Приглашение в друзья | Запрос на связь, отправленный по адресу электронной почты; действует до принятия или отклонения | REQ-FR-001 |
| Подтверждение долга | Согласие второй стороны с записью о долге; до подтверждения долг не учитывается в балансе | REQ-DEBT-005 |
| Статус долга | Состояние записи: PENDING_CONFIRMATION, ACTIVE, OVERDUE, REJECTED, CLOSED, DELETED | REQ-DEBT-005, REQ-PAY-003 |
| Просроченный долг | Активный долг, срок возврата которого прошёл; статус OVERDUE | REQ-NOT-001 |
| Погашение | Платёж, уменьшающий остаток долга; может быть частичным или полным | REQ-PAY-001 |
| Остаток долга | Сумма долга за вычетом всех погашений; не может быть отрицательным | REQ-PAY-002 |
| Закрытый долг | Долг с нулевым остатком; статус CLOSED | REQ-PAY-003 |
| Групповой долг | Долг, разделённый поровну между тремя-пятью участниками | REQ-DEBT-008 |
| Баланс | Разность между суммой, которую должны пользователю, и суммой, которую должен он, отдельно по каждой валюте | REQ-BAL-001 |
| Валюта | Одна из поддерживаемых валют: BYN, USD, EUR, RUB; пересчёт по курсу не выполняется | REQ-DEBT-003 |
| Срок возврата | Дата, к которой должник обязан вернуть долг; не раньше даты возникновения долга | REQ-DEBT-004 |
| Учётная запись | Набор данных пользователя (адрес электронной почты, имя, хэш пароля) для входа в систему | REQ-AUTH-001 |
| Аутентификация | Проверка адреса электронной почты и пароля при входе | REQ-AUTH-003 |
| Сессия | Серверное состояние входа, связанное с cookie; удаляется при выходе и блокировке | ADR-0004 |
| Блокировка учётной записи | Действие администратора, при котором вход пользователя запрещён до разблокировки | REQ-ADM-001 |
| Уведомление | Письмо, отправляемое пользователю при создании, подтверждении, погашении или сроке возврата | REQ-NOT-001, REQ-NOT-002 |
| Outbox | Таблица письменной очереди в БД, куда письмо записывается в одной транзакции с данными | ADR-0005 |
| Событие «Время» | Срабатывание по расписанию, которое проверяет сроки возврата и переводит долги в OVERDUE | REQ-NOT-001 |
| Действующее лицо (актёр) | Роль, которую человек или внешняя система играет по отношению к системе | Раздел 2.4 SRS |
| Администратор | Сотрудник поддержки, который блокирует и разблокирует учётные записи | REQ-ADM-001 |
