# Глоссарий проекта «IoT Device Emulator» (Вариант 8)

| Термин / Акроним | Определение |
| :--- | :--- |
| **IoT Device Emulator (Эмулятор устройств)** | Автономный программный сервис на Python, имитирующий работу физического датчика: периодически генерирует JSON-телеметрию и принимает управляющие команды по HTTP. |
| **Телеметрия (Telemetry)** | JSON-пакет данных о текущем состоянии виртуального сенсора (`device_id`, `timestamp`, `temperature`, `motion`, `status`), формируемый каждые $N$ секунд. |
| **Интервал опроса ($N$)** | Период времени в секундах (по умолчанию 5 с), через который эмулятор генерирует очередной пакет телеметрии. |
| **Управляющая директива (`/command`)** | HTTP POST-запрос от внешнего сервиса (Движка правил), изменяющий внутренние параметры или режим работы эмулятора без перезапуска. |
| **Режим работы (`mode`)** | Внутреннее состояние эмулятора: штатный режим (`NORMAL`) или режим симуляции аварии/перегрева (`ALERT`). |
| **Bearer Token** | Секретный строковый ключ авторизации в заголовке `Authorization: Bearer <token>`, защищающий эндпоинт `/command` от несанкционированного доступа (`FR-7`). |
| **Движок правил (Rule Engine)** | Внешняя бэкенд-система, принимающая телеметрию от эмулятора и отправляющая управляющие команды при срабатывании триггеров. |
| **Оператор / QA-инженер** | Пользователь, запускающий эмулятор через CLI с заданными параметрами и контролирующий его работу по структурированным логам. |
