# Глоссарий Task Manager

Версия 0.3. Подготовила Климова Авелина Алексеевна. Дата: 23.11.2026.

Термины применяются в [SRS](../srs.md#version-03-scope), [SDD](../sdd/sdd.md#dynamic-design), [сценариях](use-cases.md) и [ADR](../adr/adr.md#adr-0005).

| Термин | Определение |
|---|---|
| Задача | Личное дело пользователя с идентификатором, названием, статусом и необязательными атрибутами. |
| Владелец | Учётная запись, которой принадлежит задача, категория или связанная подзадача. |
| Новая | Сохранённая задача, выполнение которой ещё не начато. |
| В работе | Задача, выполнение которой пользователь начал. |
| Выполнена | Задача, завершённая пользователем; её история сохраняется. |
| Удалена | Завершённый жизненный цикл задачи; она отсутствует в активном списке. |
| Приоритет | Низкая, обычная, высокая или критическая важность; по умолчанию обычная. |
| Дедлайн | Необязательный момент, к которому требуется завершить дело. |
| Просроченность | Вычисляемый признак незавершённой задачи, чей дедлайн уже прошёл; не самостоятельный статус. |
| Категория | Именованная группа задач одного владельца. |
| Подзадача | Часть задачи со своим названием и отметкой готовности. |
| Прогресс | Доля завершённых подзадач; статус родителя меняется отдельно. |
| Правило повторения | Ежедневное, еженедельное либо ежемесячное календарное правило создания следующего экземпляра. |
| Экземпляр повторения | Новая задача с новым ID и сроком; предыдущая остаётся выполненной. |
| Сессия | Контекст вошедшей учётной записи, определяющий владельца и доступные действия. |
| Администратор | Аутентифицированный пользователь с отдельными полномочиями управления аккаунтами и диагностики. |
| Блокировка | Запрет входа и защищённых действий аккаунта без удаления его задач. |
| Напоминание | Почтовое уведомление о наступившем дедлайне незавершённой задачи. |
| SMTP-сервер | Внешняя система, принимающая почтовые сообщения; принятие не гарантирует прочтение или доставку во входящие. |
| Идемпотентность | Повтор операции не создаёт повторного результата, например второго экземпляра задачи. |
| Транзакция | Группа изменений БД, применяемая целиком или полностью отменяемая при ошибке. |
| Optimistic locking | Проверка версии записи, предотвращающая незаметную перезапись параллельных изменений. |
| UTC / zone_id | Шкала хранения моментов времени и часовая зона календарного расчёта и отображения. |
| DTO | Объект результата операции, передаваемый между слоями без раскрытия секретов хранилища. |
| C++20 / Qt 6 | Язык и фреймворк проектируемого приложения; Widgets формирует UI, Qt SQL обеспечивает доступ к БД. |
| SQLite | Встраиваемая реляционная БД выбранного стека. |
| Repository | Компонент, скрывающий SQL и преобразование записей в объекты. |
| CSV | Текстовый формат экспорта текущего отфильтрованного списка задач. |
| UML | Язык описания структуры и поведения системы. |
| Актёр | Внешняя по отношению к системе роль пользователя или сервиса. |
| Прецедент / UC | Сценарий достижения цели актёра с условиями и потоками событий. |
| include | Обязательное включение общего поведения; стрелка направлена к включаемому прецеденту. |
| extend | Условное расширение; стрелка направлена от расширения к базовому прецеденту. |
| Обобщение | Наследование возможностей роли или поведения прецедента; треугольник у общего элемента. |
| SRS / SDD / ADR | Требования, описание проектирования и запись архитектурного решения. |
| Трассировка | Связь требования, сценария, модели, проектного решения и проверки. |
| Planned | Проверка запланирована; успешное выполнение пока не подтверждено. |
