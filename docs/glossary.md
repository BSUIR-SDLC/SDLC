# Глоссарий проекта «Кабинет фрилансера» (FreelanceHub)

| Термин | Определение | Контекст / Примечание |
| :--- | :--- | :--- |
| **Фрилансер (Freelancer)** | Зарегистрированный исполнитель, осуществляющий поиск заказов по своим навыкам, подачу откликов, сдачу результатов и запрос оплаты. | Основное действующее лицо (Actor) системы. |
| **Заказчик (Client)** | Инициатор задачи/проекта, оценивающий сданный результат, подтверждающий выплату и выставляющий рейтинг исполнителю. | Внешнее действующее лицо (Actor). |
| **Задача / Проект (Task)** | Единица работы в реестре биржи, имеющая идентификатор, название, требуемый навык, бюджет и текущий статус жизненного цикла. | Основная бизнес-сущность. |
| **Навык (Skill)** | Технологическая компетенция, необходимая для выполнения задачи (например, C++, HTML/CSS, SQL, Figma). | Используется как критерий фильтрации. |
| **Отклик (Proposal)** | Заявка фрилансера на выполнение открытой задачи, содержащая сопроводительное письмо. | Переводит задачу в статус `IN_PROGRESS`. |
| **Файл-результат (Deliverable)** | Артефакт выполненной работы (архив, исходный код, макет), путь к которому прикрепляется к задаче перед сдачей. | Обязательное условие для требования оплаты. |
| **Требование оплаты (Payment Claim)** | Инициируемый фрилансером запрос на перечисление гонорара после загрузки файла-результата. | Блокируется при отсутствии файла (`SUBMITTED`). |
| **Баланс (Balance)** | Совокупный объем денежных средств, начисленных фрилансеру за успешно завершённые проекты. | Отображается в личном кабинете. |
