# Глоссарий проекта «Полка»

| Термин | Значение |
|---|---|
| Читатель | Единственная внешняя роль. Ведёт полку и переносит её на другое устройство. |
| Полка | Набор карточек читателя и общая норма месяца. |
| Карточка книги | Запись с идентификатором, названием, автором, объёмом и позицией. |
| Текущая страница | Целая позиция от нуля до объёма включительно. |
| Статус | Производная позиции: запланирована, читается или прочитана. |
| Дата завершения | Местная дата последнего перехода на последнюю страницу. |
| Событие чтения | Местная дата и положительная разница между новой и предыдущей позицией. |
| Норма месяца | Целевое число страниц, с которым сравнивается сумма событий данного месяца. |
| Снимок | Полное состояние книг, событий и нормы в одном JSON-объекте. |
| LocalStore | Часть приложения, которая проверяет и записывает снимок под ключом polka.shelf.v1. |
