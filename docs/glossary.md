\# Глоссарий проекта «EventPulse Dashboard»



| Термин | Англ. эквивалент | Определение в контексте системы |

|--------|------------------|---------------------------------|

| Мероприятие | Event | Публичное или закрытое событие (конференция, митап, концерт), создаваемое организатором, имеющее дату, площадку и общую вместимость. |

| Категория билета | Ticket Tier | Тарифный класс входного билета («VIP» или «Стандарт»), определяющий стоимость в BYN, набор привилегий и выделенный лимит мест. |

| Квота | Quota | Максимально допустимое количество билетов определённой категории, доступное для продажи на конкретное мероприятие. |

| Овербукинг | Overbooking | Критическая ошибка транзакционного учёта, при которой количество проданных билетов превышает установленную физическую квоту зала. |

| Сводная таблица продаж | Sales Summary Table | Аналитический компонент интерфейса, отображающий в реальном времени соотношение проданных билетов к квоте и суммарную выручку (BYN). |

| Промокод | Promo Code | Уникальный буквенно-цифровой идентификатор, предоставляющий покупателю процентную или фиксированную скидку при расчёте стоимости билета. |

| Организатор | Event Manager | Основной пользователь системы EventPulse, осуществляющий создание событий, управление квотами и финансовый мониторинг. |

| Администратор | Super Admin | Привилегированный пользователь системы, наследующий права Организатора и управляющий глобальными промокодами и аудитом. |
