# Глоссарий проекта FinanceTracker

| Термин | Определение |
|:---|:---|
| **Транзакция** | Единичная финансовая операция (доход или расход) с датой, суммой (`BigDecimal`), валютой и категорией. |
| **Категория** | Классификатор операций (`INCOME` или `EXPENSE`), используемый для фильтрации и аналитики. |
| **Баланс** | Итоговая разница между всеми поступлениями и списаниями, пересчитываемая в реальном времени. |
| **BigDecimal** | Класс Java для точной десятичной арифметики денежных сумм (`scale = 2`, `HALF_UP`). |
| **SQLite WAL** | Режим журналирования упреждающей записи (Write-Ahead Logging), обеспечивающий ACID-надежность. |
| **MVVM** | Архитектурный шаблон разделения интерфейса JavaFX (`View`), логики представления (`ViewModel`) и модели (`Model`). |
| **DAO** | Data Access Object — слой, изолирующий SQL-запросы к БД SQLite от бизнес-логики. |
| **CSV (RFC 4180)** | Текстовый формат экспорта табличных выписок в кодировке UTF-8 BOM для MS Excel. |
