# Глоссарий проекта TourReview

| Термин | Определение |
|---|---|
| TourReview | Desktop-приложение для отзывов и рейтингов туристических мест и объектов аренды |
| Турист (Tourist) | Пользователь, который ищет места, оставляет отзывы, оценки и жалобы |
| Арендодатель (Landlord) | Пользователь, который добавляет объекты аренды и отвечает на отзывы о них |
| Модератор (Moderator) | Пользователь с расширенными правами: обрабатывает жалобы, скрывает контент, блокирует нарушителей |
| Отзыв (Review) | Текст + оценка 1–5 + опциональное фото, оставленный туристом о месте |
| Ответ на отзыв (Reply) | Сообщение арендодателя под отзывом об его объекте |
| Жалоба (Complaint) | Обращение пользователя на отзыв/фото с указанием причины |
| Модерация | Процесс проверки жалоб и принятия решений (скрыть/оставить/заблокировать) |
| Средний рейтинг (avg_rating) | Арифметическое среднее оценок отзывов места |
| Use-case (прецедент) | Сценарий взаимодействия актора с системой для достижения цели |
| Актор (Actor) | Роль внешнего пользователя, взаимодействующего с системой |
| Предусловие (Precondition) | Условие, которое должно быть истинно до начала прецедента |
| Постусловие (Postcondition) | Условие, которое должно быть истинно после успешного завершения прецедента |
| Поток событий (Flow of Events) | Последовательность шагов основного/альтернативного сценария |
| Состояние (State) | Устойчивое положение объекта между событиями (например, «Опубликован») |
| Переход (Transition) | Смена состояния под воздействием события/условия |
| Lifeline (линия жизни) | Объект/актор, участвующий во взаимодействии на диаграмме последовательности |
| Synchronous message | Синхронное сообщение (вызов с ожиданием ответа) |
| Asynchronous message | Асинхронное сообщение (без ожидания ответа) |
| Execution specification | Полоса выполнения (активация) на линии жизни |
| Interaction use (ref) | Ссылка на другой фрагмент взаимодействия |
| Combined fragment | Комбинированный фрагмент (alt, opt, loop, par) |
| Activity | Деятельность (процесс) на диаграмме активности |
| Decision node | Узел решения (ромб) с условиями на исходящих рёбрах |
| Fork/Join | Узел разделения/синхронизации параллельных потоков |
| Final node | Конечный узел (завершение деятельности) |
