# Java 17, Swing и Maven для локального desktop-приложения

## Контекст и постановка задачи

«Автоучёт» версии 0.1 — программа учёта трат на один автомобиль. Она стоит на компьютере владельца, не обращается в сеть и не требует хостинга (SRS, раздел 2.3, REQ-COST-001, REQ-DIST-001, REQ-PORT-001). Нужно выбрать стек, на котором студент сдаёт работу на Windows и который не тащит за собой сервер.

Вопрос: на чём собирать «Автоучёт» 0.1?

Связанные требования: REQ-INST-001, REQ-BUILD-001, REQ-PORT-001, REQ-SEC-001, REQ-COST-001, REQ-DIST-001.

## Драйверы решения

* Язык проекта зафиксирован заказчиком и SRS: Java.
* Демонстрация преподавателю — Windows 10 или Windows 11, одна установленная Java 17.
* Нулевая стоимость внешних сервисов: нет платной лицензии, нет хостинга, нет ключа API.
* Интерфейс небольшой: главный экран и модальная форма. Отдельной дизайн-системы нет.
* Сборку нужно повторять командой по файлу проекта (REQ-BUILD-001).
* Срок релиза, согласованный 06.11.2026, — 20.12.2026. Стек не должен съедать недели на инфраструктуру.

## Рассмотренные варианты

* Java 17, Swing, Maven
* Java 17, JavaFX, Maven
* Веб-клиент и сервер (Spring Boot и отдельный интерфейс)

## Итог решения

Выбранный вариант: «Java 17, Swing, Maven», потому что он закрывает ограничение «desktop на Java», запускается одной командой на машине преподавателя и не добавляет сервер, который SRS прямо выводит за границу версии 0.1.

### Последствия

* Хорошо, потому что поставка — это один запускаемый архив и каталог данных пользователя. Платить за хостинг не нужно.
* Хорошо, потому что Swing входит в стандартную поставку Java, отдельный SDK интерфейса ставить не надо.
* Плохо, потому что внешний вид Swing проще, чем у современного веб-интерфейса. Для журнала трат этого достаточно, для «красивого» маркетингового экрана — нет.
* Плохо, потому что перенос на телефон этим решением не предусмотрен. Он и не входит в версию 0.1.

### Подтверждение

В `pom.xml` указаны Java 17 и сборка Maven. Точка входа открывает окно Swing. В поставке нет модуля сервера и нет зависимости с сетевым клиентом. Проверка — осмотр файла проекта и запуск на Windows (REQ-BUILD-001, REQ-PORT-001).

## Плюсы и минусы вариантов

### Java 17, Swing, Maven

Окно и форма рисуются средствами JDK. Сборка — Maven.

* Хорошо, потому что совпадает с REQ-INST-001 и REQ-BUILD-001 без дополнительных платформ.
* Хорошо, потому что лицензия JDK, которой пользуется студент на защите, не требует платы за UI-библиотеку.
* Нейтрально, потому что вёрстка таблиц и форм займёт заметную часть спринта: это учтено в оценке трудозатрат.
* Плохо, потому что автоматические UI-тесты Swing неудобны. Приёмку экранов закладываем как демонстрацию по чек-листу, расчёты — как обычные тесты без окна (REQ-REUSE-001).

### Java 17, JavaFX, Maven

Тот же язык, другой набор компонентов интерфейса.

* Хорошо, потому что компоненты выглядят современнее Swing.
* Плохо, потому что на части установок JavaFX не входит в JDK и его нужно отдельно прикладывать к поставке. Это лишний риск на защите.
* Плохо, потому что выигрыш во внешнем виде не закрывает ни одного требования SRS версии 0.1.

### Веб-клиент и сервер

Браузер, REST и база на сервере.

* Хорошо, потому что заказчику был бы знаком браузер.
* Плохо, потому что появляется сеть, хостинг и учётная запись. Это прямо запрещено REQ-SEC-001, REQ-DIST-001 и REQ-COST-001.
* Плохо, потому что срок до 20.12.2026 ушёл бы на каркас сервера, а не на журнал трат.

## Дополнительная информация

Решение согласовано с заказчиком в первом раунде переписки 06.11.2026: отдельные недели на сервер он не оплачивает, потому что пользуется программой один и офлайн.

Элементы SDD: VIEW-001, VIEW-002, VIEW-009.
Пересмотр: если появится требование синхронизации между телефоном и компьютером, это новое ADR, а не правка этого.
