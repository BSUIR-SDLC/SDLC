# ADR-0005: Редактор правил: JSON-режим с проверкой схемы, визуальный конструктор – в релиз 3

- Статус: accepted
- Дата: 12.11.2026 (изменено 13.11.2026)
- Принимающий решение: М. Н. Дешко (архитектор)
- Связанные требования: REQ-FUNC-009

## Контекст и постановка проблемы

Требуется выбрать решение: редактор правил: JSON-режим с проверкой схемы, визуальный конструктор – в релиз 3.

## Драйверы решения

- BG-1: оператор меняет правила сам
- CON-6: срок 05.03.2027
- бюджет: сокращение трудоёмкости F11 (раунд 1)

## Рассмотренные варианты

- Полный редактор: JSON, визуальный конструктор, история с diff (32 ч)
- JSON-редактор с проверкой по схеме и пробным прогоном (18 ч)
- Только API без веб-консоли

## Решение

Выбран вариант: **JSON-редактор с проверкой по схеме и пробным прогоном**. Достигает BG-1 при экономии 14 ч; конструктор и сравнение версий выделены в F20 (релиз 3). Решение принято Заказчиком в письме 4.

## Последствия

- Хорошо: срок и бюджет сохранены
- Хорошо: конструктор строится поверх той же схемы
- Плохо: операторам без опыта JSON нужны примеры (F19)

## Подтверждение

демонстрация редактора на итерации 3; тест проверки правила по схеме в браузере.

## Плюсы и минусы вариантов

### Полный редактор: JSON, визуальный конструктор, история с diff (32 ч)

- Хорошо: удобно непрограммистам
- Плохо: почти неделя работы
- Плохо: срок сдвигается на 2 рабочих дня

### JSON-редактор с проверкой по схеме и пробным прогоном (18 ч)

- Хорошо: операторы уже работают с JSON
- Хорошо: экономия 14 ч
- Хорошо: ошибки видны сразу
- Плохо: нет визуального конструктора до релиза 3

### Только API без веб-консоли

- Хорошо: экономия до 32 ч
- Плохо: нарушает BG-1
- Плохо: оператор не пользуется curl
