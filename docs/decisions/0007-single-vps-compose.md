# ADR-0007: Один VPS, Docker Compose

- Статус: accepted
- Дата: 12.11.2026
- Принимающий решение: М. Н. Дешко (архитектор)
- Связанные требования: REQ-INST-001

## Контекст и постановка проблемы

Требуется выбрать решение: один VPS, Docker Compose.

## Драйверы решения

- CON-4: бюджет
- AS-3: пик 50 событий/с, до 200 правил
- AS-4: кластер не требуется

## Рассмотренные варианты

- Docker Compose на одном VPS
- k3s (Kubernetes)
- PaaS (Render, Fly.io)

## Решение

Выбран вариант: **Docker Compose на одном VPS**. Нагрузка невелика, команда маленькая; резервные копии pg_dump закрывают AS-4.

## Последствия

- Хорошо: развёртывание одной командой (REQ-INST-001)
- Плохо: восстановление после отказа VPS – вручную по резервной копии

## Подтверждение

развёртывание с нуля в CI на чистой виртуальной машине.

## Плюсы и минусы вариантов

### Docker Compose на одном VPS

- Хорошо: просто
- Хорошо: достаточно для нагрузки
- Плохо: нет автоматического переключения при отказе VPS

### k3s (Kubernetes)

- Хорошо: масштабирование и самовосстановление
- Плохо: избыточно
- Плохо: рост затрат на сопровождение

### PaaS (Render, Fly.io)

- Хорошо: не нужно администрировать сервер
- Плохо: дороже при постоянной работе
- Плохо: зависимость от провайдера
