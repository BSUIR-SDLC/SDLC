# Описание дизайна программного обеспечения

**Для веб-приложения Medora (учёт приёма лекарств)**  
**Версия:** 0.1  
**Подготовил:** Зелень А. И.  
**Организация:** БГУИР, ФКСиС, кафедра ЭВМ  
**Дата:** 2026-11-09

## 1. Назначение

Документ описывает системные требования и проектируемую архитектуру Medora на основе согласованного SRS (лабораторная работа №3).

## 2. Обзор системы

Medora — веб-приложение для персонального учёта приёма лекарств: справочник препаратов, расписание, ежедневные отметки, напоминания, остатки и история.

Стек: Java, Spring Boot, PostgreSQL, уведомления в UI / Web Push (по согласованию).

## 3. Основные компоненты

| Компонент | Назначение |
|---|---|
| Medicine | Справочник лекарств пользователя |
| Schedule | Правила расписания приёма |
| Intake | Ежедневный обзор доз и отметки принято/пропущено |
| Stock | Учёт остатков и предупреждения |
| Notifications | Напоминания и уведомления о пропусках |
| History | История приёма |
| MedicineCard | Карточка лекарства |

## 4. Системные функциональные требования (черновик)

- REQ-FUNC-001 — Справочник лекарств
- REQ-FUNC-002 — Расписание приёма
- REQ-FUNC-003 — Ежедневный обзор доз
- REQ-FUNC-004 — Напоминания о приёме
- REQ-FUNC-005 — Уведомления о пропущенных дозах
- REQ-FUNC-006 — Учёт остатков
- REQ-FUNC-007 — История с фильтрацией
- REQ-FUNC-008 — Карточка лекарства

## 5. Архитектура (предварительно)

Клиент (браузер) → REST API (Spring Boot) → PostgreSQL.
