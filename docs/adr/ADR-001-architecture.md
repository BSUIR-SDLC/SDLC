# ADR-001. Клиент-серверная архитектура Spring Boot + PostgreSQL

## Контекст

Medora хранит персональные данные о расписании и приёме лекарств, нужна централизованная бизнес-логика и возможность добавить PDF-экспорт.

## Решение

Веб-UI + Spring Boot REST API + PostgreSQL.

## Последствия

+ Единые правила на сервере, удобно тестировать API.  
− Нужна сеть и развёртывание приложения с СУБД.
