# ADR-002. Отложить Web Push за рамки MVP

## Контекст

Оценка полного объёма уведомлений (включая Web Push) не позволяет уложиться в согласованный горизонт MVP.

## Решение

В MVP оставляем напоминания только в UI. Полноценный Web Push и расширенные уведомления о пропусках переносим на этап после релиза (REQ-FUNC-005, приоритет 50).

## Последствия

+ Сокращается объём работ спринтов 1–3.  
− Пользователь не получает системные push вне приложения до post-MVP.
