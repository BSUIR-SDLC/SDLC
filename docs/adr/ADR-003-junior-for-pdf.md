# ADR-003. Junior вместо сдвига дедлайна для PDF-экспорта

## Контекст

Заказчик потребовал REQ-FUNC-009 (PDF-отчёт) без сдвига срока релиза и без существенного роста бюджета.

## Варианты

1. Сдвинуть дедлайн на 2 недели.  
2. Урезать спринт 3.  
3. Добавить junior на 2 недели (+600 BYN).

## Решение

Выбран вариант 3: junior делает UI экспорта и вёрстку шаблона PDF, основной разработчик — серверную генерацию.

## Последствия

+ Дедлайн сохранён, PDF входит в релиз.  
− Бюджет +600 BYN, нужна координация двух разработчиков.
