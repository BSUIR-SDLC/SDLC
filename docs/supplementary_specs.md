# Дополнительные спецификации (Supplementary Specifications)

## 1. Общие положения
Данный документ фиксирует нефункциональные требования, бизнес-правила и системные ограничения проекта «Кабинет фрилансера», не вошедшие напрямую в диаграммы вариантов использования.

## 2. Функциональные ограничения и бизнес-правила
* **БП-01 (Единственность исполнителя):** На одну задачу в статусе `OPEN` может быть принят только один активный отклик, после чего задача переходит в статус `IN_PROGRESS` и скрывается из пула свободных.
* **БП-02 (Обязательность артефакта):** Невозможно перевести задачу в статус `SUBMITTED` с пустым путём к файлу или неподдерживаемым расширением.
* **БП-03 (Защита транзакций):** Кнопка «Требовать оплату» срабатывает исключительно для задач в статусе `SUBMITTED`. Повторное требование оплаты по закрытой задаче (`COMPLETED`) заблокировано.

## 3. Нефункциональные требования (NFR)
* **Производительность:** Поиск и фильтрация по стеку навыков в коллекции до 10 000 задач выполняются за время < 50 мс.
* **Надежность:** Некорректный ввод пользователя в CLI (буквы вместо чисел в меню) перехватывается без аварийного завершения программы.
* **Совместимость:** Код соответствует стандарту ISO C++17 и компилируется в среде MinGW/GCC с поддержкой кодировки UTF-8.
