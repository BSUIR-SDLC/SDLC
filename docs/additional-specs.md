# Дополнительные спецификации FinanceTracker

1. **Точность финансовых расчётов:** все суммы валидируются как `BigDecimal > 0` с масштабом ровно 2 знака после запятой; в БД хранятся в копейках/центах (`INTEGER amount_cents`).
2. **Поддерживаемые валюты:** коды по стандарту ISO 4217 (`BYN`, `USD`, `EUR`).
3. **Производительность (REQ-PERF-001):** время отклика интерфейса при добавлении, фильтрации и пересчёте баланса не превышает 200 мс на объёме до 100 000 записей.
4. **Безопасность удаления:** удаление любой транзакции выполняется только после явного подтверждения в модальном диалоге с фиксацией события в `finance_app.log`.
5. **Экспорт отчётов:** выгрузка CSV выполняется строго по RFC 4180 с добавлением маркера UTF-8 BOM (`0xEF 0xBB 0xBF`).
