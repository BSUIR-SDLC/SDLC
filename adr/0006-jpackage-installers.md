# ADR-0006. Установщики MSI и DEB, собранные jpackage со встроенной средой Java

## Контекст и постановка задачи

REQ-INST-001 требует установщики MSI и DEB, которые ставятся без прав администратора и без предустановленной Java не дольше 2 минут. Чем собирать поставку?

## Драйверы решения

* REQ-INST-001
* REQ-PORT-001
* REQ-COST-001: только бесплатные инструменты

## Рассмотренные варианты

* jpackage из JDK 21 со встроенной JRE (jlink)
* Один fat-jar
* GraalVM Native Image

## Итог решения

Выбранный вариант: «jpackage из JDK 21 со встроенной JRE (jlink)», потому что он выполняет REQ-INST-001 стандартными средствами JDK без платных инструментов.

### Последствия

* Хорошо, потому что пользователю не нужно ставить Java
* Плохо, потому что установщики нужно собирать на runner'ах обеих ОС

### Подтверждение

Сценарий `tests/install.md` на чистых виртуальных машинах Windows 11 и Ubuntu 22.04; сборка в GitHub Actions публикует артефакты с SHA-256.

## Плюсы и минусы вариантов

### jpackage из JDK 21 со встроенной JRE (jlink)

Стандартный инструмент JDK.

* Хорошо, потому что MSI и DEB собираются из одной сборки
* Нейтрально, потому что установщик весит около 60 МБ

### Один fat-jar

Запуск командой `java -jar`.

* Хорошо, потому что маленький размер
* Плохо, потому что требует установленной Java и не создаёт ярлыков

### GraalVM Native Image

Компиляция в нативный файл.

* Хорошо, потому что очень быстрый старт
* Плохо, потому что сложная поддержка JavaFX и рефлексии

## Дополнительная информация

Заменяет отдельное представление развёртывания в SDD: приложение работает на одном компьютере.
