# Выбор Java Spring Boot для Backend

## Контекст и постановка задачи
Для проекта платформы «TutorPlatform» необходимо создать надежный, безопасный REST API, который будет обрабатывать заявки на бронирование, управлять профилями репетиторов и обеспечивать безопасность пользовательских данных.

## Драйверы решения
- Безопасность (защита персональных данных и разграничение ролей, согласно SRS 3.3.2).
- Строгая типизация для снижения количества ошибок на этапе компиляции.
- Наличие готовых модулей для работы с базой данных.

## Рассмотренные варианты
1. Node.js + Express
2. Python + Django
3. Java + Spring Boot

## Итог решения
Выбран вариант **«Java + Spring Boot»**, так как он обеспечивает наилучший баланс между безопасностью, производительностью и зрелостью экосистемы для enterprise-разработки.

## Последствия
- **Хорошо**, потому что встроенный модуль Spring Security закрывает требования по защите данных, а Spring Data JPA упрощает работу с БД.
- **Плохо**, потому что разработка на Java требует больше времени из-за необходимости писать boilerplate-код.

## Подтверждение
Проверка осуществляется через Code Review (архитектурный аудит) и запуск автотестов безопасности (JUnit).

## Плюсы и минусы вариантов
- **Node.js + Express:** Хорошо (высокая скорость асинхронной обработки), Плохо (слабая типизация и меньше встроенных механизмов безопасности).
- **Python + Django:** Хорошо (быстрая разработка), Плохо (ниже производительность при высоких нагрузках).
- **Java + Spring Boot:** Хорошо (строгая типизация, надежность, масштабируемость), Плохо (более высокий порог входа).
