# Выбор стека Vite + React для Frontend

## Контекст и постановка задачи
Требуется создать быстрый, реактивный и легко поддерживаемый пользовательский интерфейс (SPA) для платформы поиска репетиторов. Интерфейс должен обеспечивать мгновенный отклик при фильтрации и поиске.

## Драйверы решения
- Скорость сборки и разработки (HMR).
- Производительность интерфейса (согласно SRS 3.3.1 — загрузка не более 2 секунд).
- Огромная экосистема готовых UI-компонентов.

## Рассмотренные варианты
1. Angular
2. Vue.js
3. React + Vite

## Итог решения
Выбран стек **Vite + React + JavaScript**. 

## Последствия
- **Хорошо**, потому что Vite обеспечивает мгновенную сборку и горячую замену модулей, а React имеет огромную экосистему компонентов и низкий порог входа.
- **Плохо**, потому что использование чистого JavaScript (без TypeScript) может привести к ошибкам типизации в больших проектах.

## Подтверждение
Проверка осуществляется через UI-тесты (Jest/React Testing Library) и замеры метрик Lighthouse.

## Плюсы и минусы вариантов
- **Angular:** Хорошо (полноценный фреймворк "из коробки"), Плохо (избыточная сложность и тяжелый порог входа).
- **Vue.js:** Хорошо (низкий порог входа), Плохо (меньшая экосистема по сравнению с React).
- **React (с Vite):** Хорошо (быстрая сборка Vite, гибкость React), Плохо (требует настройки дополнительных библиотек, например, React Router).
