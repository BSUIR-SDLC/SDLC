# ADR-0001: Модульный монолит на стеке TypeScript (React, Node.js, PostgreSQL)

- **Статус:** принято
- **Дата:** 10.11.2026
- **Автор:** _ФИО_

## Контекст

Проект выполняется одним студентом (с junior-разработчиком на 4 недели) за 10 недель. Нужен веб-интерфейс, REST API, реляционные данные с транзакциями (задачи, платежи, отзывы) и интеграция с внешними сервисами.

## Решение

- Архитектура: **модульный монолит** (модули Auth, Tasks, Applications, Payments, Reviews, Disputes, Notifications в одном приложении).
- Клиент: React + TypeScript. Сервер: Node.js + TypeScript. База данных: PostgreSQL.

## Последствия

- (+) Один репозиторий и один деплой; быстрая разработка, простая отладка.
- (+) Транзакции PostgreSQL гарантируют согласованность статусов задач и платежей.
- (+) Один язык на клиенте и сервере упрощает работу junior-разработчика.
- (−) Масштабирование только целиком; при росте нагрузки модули придётся выделять в сервисы.

## Рассмотренные альтернативы

| Вариант | Почему отклонён |
|---|---|
| Микросервисы | Слишком высокая сложность для команды и срока |
| Python / Django | Разные языки на клиенте и сервере, меньше опыта у команды |
| NoSQL-база | Данные явно реляционные, нужны транзакции |
