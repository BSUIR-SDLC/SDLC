# REQ-FUNC-010 — Таймеры

**Статус:** Предложено | **Приоритет:** Should | **Источник:** BR-001

## Формулировка
Система должна создавать, показывать и отменять таймер по голосовой команде.

## Обоснование
Таймеры позволяют выполнять бытовые задачи без переключения контекста.

## Критерии приёмки
- Таймер с заданным интервалом отображается в интерфейсе.
- По истечении интервала пользователь получает уведомление; отменённый таймер не срабатывает.

## Метод верификации
Тест TC-F010 с сокращённым тестовым интервалом.
