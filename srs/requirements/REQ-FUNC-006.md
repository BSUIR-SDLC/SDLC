# REQ-FUNC-006 — Управление громкостью

**Статус:** Предложено | **Приоритет:** Should | **Источник:** BR-001

## Формулировка
Система должна изменять, отключать и включать громкость системного вывода по голосовой команде.

## Обоснование
Громкость — частое действие, для которого неудобно прерывать работу.

## Критерии приёмки
- Команды «громче», «тише» и «без звука» изменяют системное состояние.
- Текущее значение отображается пользователю.

## Метод верификации
Тест TC-F006 с проверкой значения ALSA/PipeWire.
