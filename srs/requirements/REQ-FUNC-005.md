# REQ-FUNC-005 — Закрытие приложений

**Статус:** Предложено | **Приоритет:** Must | **Источник:** BR-001

## Формулировка
Система должна закрывать выбранное приложение по голосовой команде с учётом правила подтверждения для несохранённых данных.

## Обоснование
Функция ускоряет управление окнами, но не должна приводить к потере данных.

## Критерии приёмки
- Приложение с сохранённым состоянием закрывается по команде.
- При предупреждении о несохранённых данных действие приостанавливается до подтверждения.

## Метод верификации
Демонстрация TC-F005.
