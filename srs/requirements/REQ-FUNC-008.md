# REQ-FUNC-008 — Поиск файлов

**Статус:** Предложено | **Приоритет:** Should | **Источник:** BR-001

## Формулировка
Система должна находить файлы по имени в выбранных пользователем каталогах.

## Обоснование
Голосовой поиск сокращает время поиска документов.

## Критерии приёмки
- Результаты содержат имя и полный путь.
- При отсутствии совпадений показывается пустой результат без ошибки приложения.

## Метод верификации
Тест TC-F008 на контрольном каталоге.
