# REQ-FUNC-004 — Запуск приложений

**Статус:** Предложено | **Приоритет:** Must | **Источник:** BR-001

## Формулировка
Система должна запускать выбранное пользователем приложение по голосовой команде.

## Обоснование
Запуск программ — базовое повторяемое действие без клавиатуры.

## Критерии приёмки
- Разрешённые приложения запускаются за одну команду.
- Ошибка запуска показывается пользователю и записывается в историю.

## Метод верификации
Тест TC-F004 на трёх разрешённых и одном неизвестном приложении.
