## Описание проекwта

### Вариант 16
Разработать утилиту по декодированию текста из Азбуки Морзе.

### Функциональные требования
- Пользователь вводит последовательности точек и дефисов.
- Буквы разделяются пробелами, слова — знаком «/».
- На главной форме размещена кнопка «Ввести данные», открывающая модальное окно ввода.
- Последнее корректное значение сохраняется в модели и восстанавливается при повторном открытии диалога.

### Поддерживаемые символы
- Русская таблица Азбуки Морзе для букв А–Я (без отдельного кода Ё).
- Цифры 0–9.
- Знаки: «.», «,», «?», «-».

### Модель подсчёта
- Количество декодированных сигналов.
- Количество слов.

### Обработка некорректных данных
Некорректными считаются:
- Пустой ввод;
- Посторонние символы;
- Неизвестный код;
- Лишний разделитель слов;
- Строка длиннее 1000 символов.
