# Task Manager

Кроссплатформенное приложение для личного списка дел: задачи, приоритеты, дедлайны, категории, подзадачи и календарные повторения. Подготовила Климова Авелина Алексеевна.

Проектируемый стек: C++20, Qt 6 Widgets, Qt SQL и SQLite. Версия 0.3 дополняет модель напоминаниями и администрированием. История требований и план P2 версии 0.2 сохраняются.
