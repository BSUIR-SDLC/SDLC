# Проект по дисциплине ЖЦРПО

**Автор**: Лагутик Роман, гр. 450504

**Дисциплина**: Жизненный цикл разработки программного обеспечения (ЖЦРПО)

**Описание проекта**: «Сводка» — локальное веб-приложение на Spring Boot, которое собирает новости из RSS/Atom-лент в единый список, хранит их в кэше SQLite и работает при недоступности сети.
