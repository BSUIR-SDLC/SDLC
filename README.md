## Описание проекта

Учебный проект, созданный в рамках лабораторных работ по дисциплине «Жизненный цикл разработки ПО».  
В проекте будут выполняться задания по проектированию и разработке программного обеспечения с использованием современных методологий и стандартов (IEEE, ISO).

## Структура репозитория

- `docs/` — проектная документация (SRS, SDD, ADR)
- `srs/` — шаблоны спецификаций требований
- `sdd/` — шаблоны описания дизайна
- `adr/` — шаблоны архитектурных решений
- `src/` — исходный код проекта
- `lab1/` — материалы лабораторной работы №1 (в отдельной ветке)
