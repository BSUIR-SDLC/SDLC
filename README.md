## Описание проекта

Репозиторий создан как fork учебного репозитория
[BSUIR-SDLC/SDLC](https://github.com/BSUIR-SDLC/SDLC) и используется для выполнения
лабораторных работ по дисциплине. В нём последовательно выполняются все этапы
жизненного цикла программного продукта:

1. анализ и спецификация требований (SRS) — по шаблонам из папки `srs/`;
2. проектирование архитектуры (SDD) и фиксация архитектурных решений (ADR) — по шаблонам из папок `sdd/` и `adr/`;
3. разработка программного обеспечения — в папке `project/`;
4. тестирование, сборка и сопровождение.

Проект курса — **SubScope**, веб-приложение для учёта подписок и регулярных платежей:
суммарные расходы в базовой валюте по официальному курсу НБ РБ, напоминания на e-mail и
в Telegram перед списанием и окончанием пробного периода, месячный лимит расходов,
совместные подписки, контроль использования и рекомендации по отмене. Стек: Java 17,
Spring Boot 3, Thymeleaf, PostgreSQL, Flyway (обоснование — в ADR).

## Сборка и запуск

Требуется JDK 17+ и Maven 3.8+ (или IntelliJ IDEA со встроенным Maven), для запуска — PostgreSQL 15+.

```bash
cd project
mvn verify                      # сборка и модульные тесты
java -jar target/subscope.jar   # запуск; параметры БД — переменные DB_URL, DB_USER, DB_PASSWORD
```

При первом запуске Flyway создаёт схему базы данных. Подробнее — [project/README.md](project/README.md).
