## Описание проекта
Программный проект представляет собой настольное приложение «Авторынок», разрабатываемое на объектно-ориентированном языке программирования C++ с использованием библиотеки графического интерфейса Qt Widgets.

Основные функции разрабатываемой системы:
- ведение электронного каталога автомобилей, выставленных на продажу (марка, модель, год выпуска, пробег, тип двигателя, стоимость, статус);
- добавление, редактирование и удаление карточек транспортных средств;
- многокритериальный поиск, фильтрация и сортировка автомобилей по параметрам;
- формирование сводной статистики и оформление заявок на покупку.
