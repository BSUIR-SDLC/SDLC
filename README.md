# TicketFlow

Репозиторий содержит начальную структуру проекта для последующего
проектирования и разработки системы продажи билетов TicketFlow.

## Автор

- Автор: Анастасия Бельская
- Группа: 450502
- Дисциплина: «Жизненный цикл разработки программного обеспечения»

## Назначение проекта

TicketFlow предназначен для продажи билетов на мероприятия и контроля входа.
Подготовлены требования SRS, описание проектирования SDD и записи ADR.
Maven-проект project содержит начальную структуру; прикладная функциональность
будет реализована на следующем этапе.

## Технологии

Планируемые технологии:

- Java 17 — язык программирования.
- Maven — управление зависимостями и сборка.
- IntelliJ IDEA — среда разработки.
- Git и GitHub — контроль версий и хранение проекта.

## Получение проекта

Склонируйте ветку с шаблоном:

    git clone --branch ProjectTemplate https://github.com/darfe-e/SDLC.git

## Открытие проекта

1. Запустите IntelliJ IDEA.
2. Выберите File → Open.
3. Откройте папку project внутри склонированного репозитория.
4. Дождитесь загрузки Maven-проекта.

## Сборка

Выполните:

    cd SDLC/project
    mvn clean package

## Состояние разработки
