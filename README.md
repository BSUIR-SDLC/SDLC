# FitSchedule — сквозной проект курса ЖЦРПО

Web-приложение для управления расписанием фитнес-клуба и записи на групповые и персональные тренировки
(Java 21, Spring Boot 3, React, PostgreSQL 16).

Автор: Лесковский Е. Е., гр. 450501, БГУИР, кафедра ЭВМ.

## Ветки

- `main` — согласованные версии документов;
- `lab1` — лабораторная работа № 1;
- `docs/lab3` — бизнес-требования (SRS);
- `docs/lab4` — системные требования (SDD, ADR, план);
- `docs/lab5` — модель динамического поведения на UML (прецеденты, активность, состояния, последовательность);
- `docs/lab6` — модель статической структуры на UML (классы, компоненты, развёртывание).

Текстовое описание диаграмм — `docs/uml/diagrams/*.puml` (PlantUML, расширение для VS Code). Изображения в
`docs/uml/img` оформлены по ГОСТ 19.701-90 (активность), диаграммы последовательности, классов, компонентов и развёртывания — на листах формата А3.
