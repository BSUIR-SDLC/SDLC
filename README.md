# Астрологический калькулятор судьбы (MVC Active Model)

## Описание проекта

Десктопное графическое приложение, разработанное на языке **Java** (JDK 17) с использованием библиотек Swing. Программа реализует вариант 2 индивидуального задания: расчет дня недели по введенной дате рождения (день, месяц, год) с последующим выводом астрологического предсказания судьбы[cite: 9].

## Архитектура

Проект спроектирован в соответствии с архитектурным паттерном **MVC (Model-View-Controller)** с использованием **активной модели**[cite: 9]:

- **Model (`AstrologyModel`)** — хранит состояние данных (день, месяц, год, день недели), реализует бизнес-логику валидации (с использованием `LocalDate.of()`) и шаблон проектирования «Наблюдатель» (`ModelListener`) для автоматического уведомления представления об изменениях[cite: 9].
- **View (`MainView`, `InputDialog`)** — графический интерфейс пользователя на базе Swing. Главное окно отображает текущую дату и предсказание, а модальное окно служит для ввода данных с автозаполнением последних успешных значений[cite: 9].
- **Controller (`AstrologyController`)** — обрабатывает пользовательский ввод, осуществляет парсинг строк в числовые значения, перехватывает ошибки валидации и управляет жизненным циклом диалогового окна[cite: 9].
