# Глоссарий проекта Planora

| Термин | Определение |
|---|---|
| Пользователь | Владелец учётной записи Planora, который управляет своими планами. |
| Администратор системы | Операционная роль, обслуживающая развертывание; не просматривает личные записи через пользовательский интерфейс. |
| Учётная запись | Идентифицированный пользователь и его параметры входа и предпочтения. |
| Задача | Личная работа с названием, описанием, сроком и состоянием выполнения. |
| Событие | Календарная запись с названием, датой и временем начала и окончания. |
| Заметка | Личная текстовая запись пользователя. |
| Цель | Долгосрочный результат пользователя с описанием и целевой датой; функция описана в SRS и отложена за пределы текущего релиза. |
| Напоминание | Запланированное уведомление внутри приложения о задаче или событии. |
| CSV | Текстовый табличный формат обмена данными, применяемый для экспорта и импорта пользовательских записей. |
| Предпросмотр импорта | Результат разбора CSV с числом записей и ошибками формата до подтверждения и записи. |
| Владелец записи | Учётная запись, которой принадлежит задача, событие, заметка, цель или напоминание. |
| Сессия | Серверное состояние аутентификации пользователя, связанное с защищённой cookie браузера. |
| API | Документированный интерфейс обмена между веб-клиентом и сервером. |
| SRS | Спецификация требований к программному обеспечению. |
| SDD | Описание проектных решений и структуры программного обеспечения. |
| ADR | Запись архитектурного решения с контекстом, вариантом и последствиями. |
| UML | Унифицированный язык моделирования программных систем. |
| Прецедент (Use Case) | Описание взаимодействия внешнего актора с системой для достижения цели. |
| Актор | Внешняя по отношению к моделируемой системе роль, взаимодействующая с ней. |
| Предусловие | Условие, которое должно выполняться до начала сценария прецедента. |
| Постусловие | Гарантируемое состояние системы после успешного завершения сценария. |

Источники терминов: [SRS Planora](../srs/planora-srs.md), [SDD Planora](planora-sdd.md) и материалы лабораторной работы № 4.
