# UML-модель Planora

Исходники диаграмм записаны на PlantUML и соответствуют UML 2.x. Их можно просматривать в PlantUML-совместимом редакторе или собирать локальным PlantUML. Каждая диаграмма хранится отдельным `.puml` файлом.

| Диаграмма | Назначение |
|---|---|
| [Варианты использования](use-cases.puml) | Границы системы, актор и цели пользователя |
| [Активность — импорт CSV](activity-import-csv.puml) | Ветвление процесса от выбора файла до атомарного импорта |
| [Состояния задачи](task-state.puml) | Жизненный цикл задачи и допустимые переходы |
| [Последовательность — сохранение задачи](sequence-save-task.puml) | Взаимодействие UI, API, сессии, сервиса и хранилища |

Текстовые описания акторов и прецедентов, включая пояснения, предусловия, потоки и постусловия, находятся в [спецификации вариантов использования](../planora-use-cases.md). Общие термины — в [глоссарии](../planora-glossary.md), общие правила — в [дополнительных спецификациях](../planora-additional-specifications.md).
