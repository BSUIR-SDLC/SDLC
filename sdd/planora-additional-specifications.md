# Дополнительные спецификации Planora

Этот файл фиксирует общие правила сценариев, дополняющие SRS и UML-модель. Он не заменяет идентифицированные требования SRS.

## Границы модели

- Внешний актор первой версии — Пользователь. Администратор системы является операционной ролью и взаимодействует с развертыванием вне пользовательских сценариев.
- Все личные записи принадлежат одной учётной записи. Совместный доступ и командные пространства не входят в первую версию.
- Взаимодействие клиента с сервером выполняется по HTTPS через JSON API; сервер хранит данные в PostgreSQL.
- Цели остаются в модели данных и спецификации, но функция отложена за пределы текущего релиза согласно согласованному плану Lab 4.
- Доставка напоминаний предусмотрена только в открытом приложении; гарантии доставки при закрытом приложении нет.

## Общие правила прецедентов

1. Перед доступом к личным данным пользователь должен пройти аутентификацию.
2. Сервер определяет владельца из аутентифицированной сессии; клиент не задаёт владельца в теле запроса.
3. Чтение, изменение и удаление записи ограничиваются текущим владельцем. Чужая или отсутствующая запись не раскрывается и возвращает одинаковый результат `404`.
4. Изменения валидируются и сохраняются транзакционно. Интерфейс показывает успех только после подтверждения сервера.
5. При ошибке сеть/валидация интерфейс сообщает об ошибке и сохраняет введённые значения формы; незавершённая операция не считается успешной.
6. Импорт CSV сначала проходит предварительный разбор. Запись выполняется только после явного подтверждения, одной транзакцией; некорректный файл не приводит к частичному импорту.
7. Даты и временные отметки передаются в ISO 8601; моменты времени хранятся в UTC, а календарный часовой пояс берётся из настроек пользователя.

## Связанные требования

| Правило | Источник SRS / ADR |
|---|---|
| Аутентификация и выход | REQ-FUNC-001, REQ-FUNC-017; ADR-0002 |
| Изоляция данных | REQ-FUNC-002, REQ-FUNC-018, REQ-SEC-001—005; ADR-0002 |
| Сохранение и обработка ошибок | REQ-FUNC-016, REQ-INT-004, REQ-REL-001—002 |
| Импорт и экспорт CSV | REQ-FUNC-019—020 |
| Время и настройки календаря | REQ-FUNC-008—009, REQ-FUNC-013 |
