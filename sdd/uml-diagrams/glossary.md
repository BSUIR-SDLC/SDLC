# Глоссарий проекта

| Термин | Определение |
|---|---|
| TicketFlow | Веб-система продажи электронных билетов и онлайн-контроля входа. |
| Актер | Внешняя по отношению к системе роль пользователя или сервиса. |
| Прецедент / вариант использования | Поведение системы, дающее наблюдаемый результат актеру. |
| include | Обязательное включение поведения другого прецедента; стрелка к включаемому. |
| extend | Условная вставка поведения в точке расширения; стрелка к базовому прецеденту. |
| Мероприятие | Событие с владельцем, площадкой, расписанием и окном продаж. |
| Тип билета | Цена BYN и назначенные секторы/места; 1–5 типов в мероприятии. |
| Место | Уникальная тройка сектор–ряд–номер в мероприятии; единица инвентаря. |
| Квота | Количество мест типа, включённых в продажу. |
| Заказ / Order | Покупка 1–5 разных мест одного типа одного мероприятия; сохраняет цену. |
| Резерв / HELD | Временное удержание всех мест заказа; expires_at=min(last_activity+1200 s,sales_close). |
| Окно продаж | Полуоткрытый интервал [sales_open,sales_close), проверяемый сервером. |
| Сессия | Серверная запись входа, истекающая через 900 секунд бездействия; не тождественна резерву. |
| Явное действие | Принятый защищённый запрос владельца, который может однократно продлить действующий резерв. |
| PaymentGateway | Порт адаптера внешнего тестового платёжного провайдера. |
| PaymentEvent | Уникально идентифицируемое уведомление, записываемое с бизнес-эффектом в одной транзакции. |
| Идемпотентность | Повтор идентифицированного запроса/события возвращает прежний результат без повторного эффекта. |
| Поздний успех | Подлинное новое подтверждение на границе срока резерва/продаж или позже; REQUIRES_REVIEW без билетов. |
| QR-токен | Непредсказуемый идентификатор билета; доступен владельцу и службе проверки. |
| Admission / допуск | Единственная успешная фиксация входа по билету с серверным временем и контролёром. |
| Снимок сводки | Один согласованный read-only снимок PostgreSQL с общим snapshot_at. |
| Guard / условие | Булево условие в квадратных скобках, разрешающее переход. |
| Линия жизни | Вертикальный пунктир существования участника взаимодействия. |
| Активация | Узкий прямоугольник исполнения операции на линии жизни. |
| Транзакция | Единый commit или rollback связанных изменений; не изображается вилкой параллелизма. |
