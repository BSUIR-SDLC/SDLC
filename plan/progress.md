# Ход реализации по плану

Проект: 3D Security Monitoring Center. План: [plan-v3.md](plan-v3.md) (согласованный).

Файл фиксирует, как выполняются итерации согласованного плана. Исходный код системы ведётся в отдельном закрытом репозитории проекта `hancoure1337/3d-security-monitoring` и в учебный репозиторий не копируется: здесь хранятся документация и отметки о ходе работ. Каждая задача ссылается на запрос на слияние (PR) в репозитории проекта, где можно посмотреть код и тесты.

## Итерация 1 (23.11.2026 – 04.12.2026): F01 «Server core and database»

Цель итерации по плану: каркас сервера, миграции, пул соединений, журнал работы. Требования: REQ-INT-009, REQ-OBS-001, REQ-BUILD-001, REQ-SEC-010.

| № | Задача | Требование | Где в проекте | Проверка | Статус |
|---|---|---|---|---|---|
| 1 | Начальная схема базы данных: здания, помещения, хосты, события, правила, инциденты, пользователи, журнал аудита | REQ-INT-009 | `db/migrations/0001_init.sql`, PR #6 | схема применяется к пустой базе PostgreSQL 16 | выполнено |
| 2 | Миграция для ядра сервера: время закрытия инцидента, номер пачки, права ролей | REQ-INT-009, REQ-SEC-008 | `db/migrations/0002_server_core.sql`, PR #11 | миграция применяется после 0001 | выполнено |
| 3 | Партиции событий по дням и отдельные пользователи базы с минимальными правами | REQ-SEC-010, REQ-PERF-005 | `db/migrations/0003_partitions_and_db_users.sql`, PR #13 | у пользователя `smc_audit` есть только INSERT и SELECT на `audit_log`, у `smc_app` доступа к журналу нет | выполнено |
| 4 | Чтение конфигурации сервера из файла JSON | REQ-INST-001 | `server/src/config.cpp`, PR #14 | `server/tests/config_test.cpp` | выполнено |
| 5 | Журнал работы со временем, уровнем и компонентом без секретов | REQ-OBS-001 | `server/src/logging.cpp`, PR #14 | пароли базы берутся из переменных окружения и в журнал не выводятся, журнал запуска просмотрен | выполнено |
| 6 | Пул соединений с базой и применение миграций при запуске | REQ-INT-009 | `server/src/db/pool.cpp`, `server/src/db/migrator.cpp`, PR #14 | `server/tests/migrator_test.cpp`, `server/tests/conninfo_test.cpp` | выполнено |
| 7 | Сборка сервера одной командой CMake с vcpkg и проверка в CI | REQ-BUILD-001 | `CMakePresets.json`, `.github/workflows/ci.yml`, PR #14 | сборка в GitHub Actions проходит | выполнено |

Итог итерации: функция F01 реализована в объёме плана, трудоёмкость итерации не превышена. Следующая итерация по плану – F02 «Secure channels and PKI» и начало F03 «Login and role-based access» (07.12.2026 – 18.12.2026).
